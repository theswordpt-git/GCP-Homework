How to set a billing alert in GCP

Step 1: Navigate to Budgets & Alerts
Go to the Google Cloud Console.
Open the navigation menu (☰) → Billing.
If prompted, select your Cloud Billing account.
In the left sidebar, under Cost management, click Budgets & alerts
(For project-scoped access: Select your project first in the console, then navigate to Billing.)

Give the budget a name, set a time range, and select which projects/organizations and services 
you want to monitor, and hit next.
Set a budget type and amount, then hit next.

Set your alert levels (typically 50%, 90%, and 100%) and under manage notifications, select email alerts
for billing admins and project owners.  Then hit finish.
